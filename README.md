JumpKneeDataAlignment

This repository contains a set of MATLAB and Python scripts designed to synchronize electromyography (EMG) and 3D motion capture data collected during drop vertical jump (DVJ) trials. The goal is to facilitate the analysis of knee biomechanics by aligning EMG signals with corresponding motion data.

Repository Structure

JumpKneeDataAlignment/
├── Final Deliverables.pdf # Full project report
├── Final Presentation.pptx # Final presentation slides
├── README.md # This file
├── OutcomeFiles/
│ ├── EMG_Plots/ # PNG images generated from EMG CSV files
│ └── EMG_utc_hpf.csv # Extracted UTC start times from EMG .hpf files
└── Scripts/
├── align_all_subject_trials.py # Aligns EMG and motion files by time
├── emg_viewer.mlx # Interactive MATLAB viewer for EMG signal
├── extract_utc.py # Extracts UTC timestamps from EMG .hpf files
└── plot_emg_batch.m # Batch plots EMG CSV files for visual inspection

Final Deliverables.pdf: Comprehensive project report detailing objectives, methodology, results, and team contributions.
plot_emg_batch.m: MATLAB script that processes a batch of EMG CSV files to generate high-resolution plots for visual inspection.
emg_viewer.mlx: MATLAB live script for detailed examination of individual EMG signals, including zoomed-in views for precise analysis.
extract_utc_from_hpf.py: Python script that extracts UTC start times from EMG .hpf files and compiles them into a CSV file for synchronization purposes.
align_all_subject_trials.py: Python script that aligns EMG data with corresponding 3D motion capture data based on extracted UTC timestamps, outputting the results into the aligned_subject_trials/ directory.
EMG/CSV/: Directory containing raw EMG data in CSV format.
EMG/Plots/: Directory where the plot_emg_batch.m script saves generated EMG plots.
EMG/EMG_utc_hpf.csv: CSV file containing extracted UTC start times from .hpf files, generated by extract_utc_from_hpf.py.
Raw Files/EMG/EMG_hpf_files/: Directory containing raw EMG data in .hpf format.
aligned_subject_trials/: Directory where aligned EMG and motion capture data are saved after processing.
Usage Instructions

Extract UTC Timestamps:
Run extract_utc_from_hpf.py to extract UTC start times from .hpf files.
This will generate EMG/EMG_utc_hpf.csv.
Generate EMG Plots:
Run plot_emg_batch.m to process EMG CSV files and generate plots.
Plots will be saved in EMG/Plots/.
View Individual EMG Signals:
Use emg_viewer.mlx to inspect individual EMG signals in detail.
Align EMG and Motion Data:
Run align_all_subject_trials.py to align EMG data with motion capture data.
Aligned data will be saved in aligned_subject_trials/.
